## Rules for any new image

- Only the public sample profile, or Francisco's own face. Never a family member, never a visitor's profile.
- No third-party brands or logos; use generic product names such as "Niacinamide serum (SAMPLE)".
- No invite code, admin token, API key or query strings in the URL bar.
- Keep the REAL / SIMULATED / SAMPLE badge, the exact disclaimer and "Powered by YouCam API" visible where relevant.
- Mobile at native resolution; desktop at 1280 px width or more.
